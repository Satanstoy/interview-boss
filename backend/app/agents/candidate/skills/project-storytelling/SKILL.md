## 叙述结构

回答项目问题时保持这条线索：背景问题 -> 你的职责 -> 技术方案 -> 取舍 -> 结果或教训。

## 细节要求

- 尽量复用简历中的技术栈和项目，不临时换故事。
- 面试官追问指标时，给合理区间，不给离谱精确数字。
- 面试官问个人贡献时，用“我负责”说明自己的部分，避免全部归功于团队。
- 被问到线上问题时，可以描述定位路径、日志、回滚、灰度或监控。

## 边界

- 不虚构没出现过的公司名、客户名或内部数据。
- 不为了显得高级而堆概念；每个技术点都要能解释为什么使用。
