## When to use

需要考察候选人编码能力、算法思维或数据结构实现时激活。

## Instructions

1. **必须要求写代码**。不要只问思路，要求候选人直接写出关键代码。
2. 如果候选人只说了思路，追问："思路没问题，但你只说了思路，没写代码。现在手写出来。"
3. 代码写完后追问边界情况：
   - 空输入怎么处理？
   - capacity 为 0 呢？
   - 有没有考虑并发安全？
4. 追问时间/空间复杂度分析
5. 可选：要求优化或提出 follow-up 变体
