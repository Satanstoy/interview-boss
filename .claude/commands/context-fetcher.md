# Context Fetcher

你需要根据任务类型，自动调用合适的 MCP 工具来补充上下文信息。

## 实时信息查询 (exa)

**触发条件：** 需要最新/实时信息时自动搜索，包括但不限于：
- 最新版本、发布动态、changelog
- 价格、可用性、服务状态
- 近期新闻、事件、公告
- 公司信息、产品信息

**工具：**
- `mcp__exa__web_search_exa` — 用自然语言描述搜索意图，不要用关键词拼凑
- `mcp__exa__web_fetch_exa` — 搜索结果不够时，读取完整页面内容

## 开发文档查询 (context7)

**触发条件：** 仅在以下情况使用（**尽量不用，优先依赖自身知识**）：
- 正在使用不确定 API 细节的库/框架
- 涉及大版本迁移，不确定是否有 breaking changes
- 较小众或近期频繁更新的库，API 可能已变化

**工具：**
1. `mcp__context7__resolve-library-id` — 获取库的 context7 ID
2. `mcp__context7__query-docs` — 用 ID + 具体问题查询文档

## 不需要查询的情况

- 仓库内已有相关代码 → 直接读代码
- 通用编程概念、确定不会过时的知识 → 直接回答
- 只是想确认一下 → 优先用自身知识，不确定时再查
