# Bug 预览报告

**日期:** 2026-06-02
**问题:** 聚类与 compaction 系统存在多个数据一致性和逻辑缺陷
**严重程度:** Critical（3 个 HIGH 级别 bug）

## 初步诊断

### 问题现象
1. Phase 1.5 匹配功能完全失效，LLM 调用白白浪费
2. LLM 幻觉可能导致一道题被合并到多个聚类中（数据损坏）
3. v2 compaction 无验证保护，LLM 错误直接写入数据库

### 根本原因
- ID 空间不匹配导致验证逻辑永远拒绝 Phase 1.5 的匹配结果
- LLM 返回重复 `new_id` 时无去重保护
- v2 compaction 跳过了 v1 中存在的 `_validate_merges` 步骤

### 影响范围
- **功能:** 增量聚类的 Phase 1.5 子阶段完全无效；compaction 可能产生错误合并
- **用户:** 所有使用题库的用户（题目去重质量下降）
- **数据:** 可能导致 frequency 膨胀、聚类内混入不相关题目

## 风险评估

| 风险类型 | 等级 | 说明 |
|---------|------|------|
| 功能中断 | HIGH | Phase 1.5 匹配完全不工作 |
| 数据完整性 | HIGH | LLM 幻觉可导致一题多合并 |
| 安全风险 | LOW | 无直接安全风险 |
| 性能影响 | MEDIUM | full_recluster O(N*M) 复杂度 |
