# Bug 预览报告

**日期:** 2026-05-10
**问题:** 高频题库中来源详情的显示不一致：有 original_questions 的题目每条来源独立显示并带操作按钮，无 original_questions 的题目来源以扁平标签内联显示且只有"合并到"按钮
**严重程度:** Medium

## 初步诊断

### 问题现象
在高频题库中展开"来源详情"时：
- **有 `original_questions` 的题目**：每个原始题目独占一行卡片，附带来源链接、"独立"和"合并到"按钮
- **无 `original_questions` 的题目**（单题多来源）：来源以 `inline-flex` 标签横向排列，仅显示公司|轮次，只提供一个"合并到"按钮

用户期望：每个来源都各占一行卡片，且都有"独立"和"合并到"按钮。

### 根本原因
QuestionCard.vue 中有两个互斥的模板分支：
1. **Lines 141-168**: `v-if="question.original_questions && question.original_questions.length > 0"` — 使用卡片布局
2. **Lines 170-185**: `v-else-if="question.sources && question.sources.length > 0"` — 使用扁平标签布局

分支 2 的 UI 设计与分支 1 不一致：缺少卡片包裹、缺少序号、缺少"独立"按钮。

### 影响范围
- **功能:** 高频题库来源详情的显示和操作
- **用户:** 所有用户（显示不一致），管理员（缺少操作入口）
- **数据:** 不影响数据完整性，纯 UI 问题

## 风险评估

| 风险类型 | 等级 | 说明 |
|---------|------|------|
| 功能中断 | Low | 功能可用，但不一致 |
| 数据完整性 | None | 纯前端展示问题 |
| 安全风险 | None | 无安全影响 |
