# Bug 预览报告

**日期:** 2026-05-07
**问题:** 多个 API 端点存在权限提升漏洞，普通用户可越权修改公共题库数据
**严重程度:** Critical

## 初步诊断

### 问题现象
普通用户可以通过直接调用 API 绕过前端限制，执行以下越权操作：
1. 为任意题目（包括公共题目和其他用户的个人题目）重新生成/覆盖 AI 答案
2. 批量为任意题目生成答案
3. 在不可见的题目上记录练习历史
4. 查看所有用户的全局分析数据

### 根本原因
- `generate-answer` 和 `batch-generate-answers` 端点仅检查用户是否登录（`get_current_user`），未校验题目是否在用户可见范围内
- `evaluate-answer` 端点未校验 `question_id` 对应的题目是否属于用户可见范围
- `analytics` 端点的 `jd` 和 `questions_detail` 查询未按 `bank_mode` 过滤

### 影响范围
- **功能:** 公共题库答案可被任意用户覆盖、练习记录可注入、分析数据泄露
- **用户:** 所有普通用户均可利用
- **数据:** 可导致公共题库 AI 答案被篡改，练习统计数据失真

## 风险评估

| 风险类型 | 等级 | 说明 |
|---------|------|------|
| 功能中断 | High | 公共题库答案可被任意覆盖 |
| 数据完整性 | High | 练习历史可注入不可见题目 |
| 安全风险 | Medium | 用户数据横向泄露（analytics） |
