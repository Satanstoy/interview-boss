# Bug 预览报告

**日期:** 2026-05-07
**问题:** 权限控制审计 — 后端运行时错误 + 前端管理员操作对普通用户可见
**严重程度:** Critical (BUG-001 运行时崩溃) / Medium (BUG-002~008 UI 权限)

## 初步诊断

### 问题现象
1. 普通用户调用 `build-personal` 接口时，后端抛出 `NameError: name 'admin' is not defined`，接口必定崩溃
2. 普通用户在前端可以看到并点击所有管理员专用按钮（重建题库、重新分类、独立/合并、删除、内联编辑、批量操作等），点击后收到 403 错误

### 根本原因
1. **BUG-001**: `master_bank.py:420` 在 `build_personal_bank` 函数中引用了未定义的 `admin['id']`，应为 `user['id']`
2. **BUG-002~008**: 前端未对管理员专用 UI 元素添加 `v-if` 权限守卫，所有按钮对所有登录用户可见

### 影响范围
- **功能:** `build-personal` 接口完全不可用（运行时崩溃）；管理员操作 UI 对普通用户可见但后端正确拒绝
- **用户:** 所有普通用户
- **数据:** 不影响数据完整性（后端权限检查正确）

## 风险评估

| 风险类型 | 等级 | 说明 |
|---------|------|------|
| 功能中断 | **Critical** | BUG-001: 个人题库重建功能完全不可用 |
| 用户体验 | **High** | BUG-002~008: 普通用户看到大量无法使用的按钮 |
| 数据完整性 | None | 后端权限检查正确，数据安全 |
| 安全风险 | None | 后端 `get_admin_user` 正确拒绝非管理员请求 |
