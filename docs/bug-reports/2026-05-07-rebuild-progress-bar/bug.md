# Bug 详细分析报告

**Bug ID:** BUG-001
**发现日期:** 2026-05-07
**状态:** 已确认

## 问题概述
全量重建题库功能的后端已实现完整的 SSE 进度推送机制，但前端未消费这些事件，导致用户在重建过程中完全无法感知进度。

## 根本原因分析

### BUG-001: 前端未消费 SSE 进度事件
- **位置:** `frontend/src/App.vue:911`
- **症状:** 点击"重建题库"后，按钮变为"重建中..."，直到重建完成才弹出 toast，中间无任何进度提示
- **根因:** `triggerBuildMasterBank` 调用 `api.buildMasterBankSSE(() => {})` 时传入了空函数作为 `onEvent` 回调。后端推送的 `init`、`progress`（tag/cluster/merge/save 四个阶段）、`error` 事件全部被丢弃
- **影响:** 用户体验极差，长时间操作无反馈，可能误以为系统卡死
- **严重程度:** P2

## 后端已有的 SSE 事件（无需修改）

后端 `master_bank.py:145-357` 已发送以下完整进度事件：

| 阶段 | 事件 type | step 字段 | 进度字段 | 消息示例 |
|------|----------|----------|---------|---------|
| 初始化 | `init` | `tag` | `total`: 批次数 | "开始重建: 120 道原始题目, 4 批标注" |
| LLM 标注 | `progress` | `tag` | `current/total` | "LLM 标注 2/4 批" |
| 聚类去重 | `progress` | `cluster` | 无进度 | "LLM 聚类去重中 (120 道)..." |
| 统一问题 | `progress` | `merge` | `current/total` | "统一问题 5/20" |
| 写入题库 | `progress` | `save` | 无进度 | "写入题库..." |
| 完成 | `done` | - | `total_unique/restored` | - |
| 错误 | `error` | - | - | "重建失败: ..." |

## 复现步骤
1. 以管理员身份登录
2. 切换到"高频题库"标签
3. 点击"重建题库"按钮，确认对话框
4. **预期:** 显示阶段名称和进度百分比/数量
5. **实际:** 按钮仅变为"重建中..."，无任何进度信息，直到完成弹出 toast

## 修复建议
1. 在 `triggerBuildMasterBank` 中传入有效的 `onEvent` 回调处理进度事件
2. 新增响应式状态变量追踪当前阶段和进度
3. 将静态"重建中..."按钮替换为带进度信息的 UI
