# Bug 预览报告

**日期:** 2026-05-07
**问题:** 全量重建题库时前端未消费 SSE 进度事件，用户处于完全黑箱状态
**严重程度:** Medium

## 初步诊断

### 问题现象
用户点击"重建题库"按钮后，按钮文字变为"重建中..."，之后没有任何进度反馈。重建过程可能持续数分钟（LLM 标注 + 聚类 + 统一问题生成），用户无法得知当前处于哪个阶段、完成了多少，也无法判断是否卡死。

### 根本原因
后端 `master_bank.py` 已通过 SSE 协议推送完整的进度事件（init / progress / done / error），但前端 `App.vue:911` 调用 `buildMasterBankSSE` 时传入了空回调 `() => {}`，导致所有进度事件被丢弃：

```javascript
const result = await api.buildMasterBankSSE(() => {})  // onEvent 被忽略
```

对比"批量生成功能"正确消费了 SSE 事件并展示了进度条。

### 影响范围
- **功能:** 重建题库功能的用户体验，功能本身不受影响（重建仍会正常完成）
- **用户:** 管理员用户（需要 `is_admin` 权限才能触发重建）
- **数据:** 不影响数据完整性

## 风险评估

| 风险类型 | 等级 | 说明 |
|---------|------|------|
| 功能中断 | Low | 重建功能本身正常，只是缺少进度展示 |
| 数据完整性 | None | 不涉及数据变更风险 |
| 安全风险 | None | 纯前端 UI 问题 |
| 用户体验 | High | 长时间无反馈导致用户可能误以为卡死而刷新页面 |
