# Bug 预览报告

**日期:** 2026-05-07
**问题:** 前端用户体验问题集合 — 涉及登录、搜索、交互、响应式、可访问性等多个方面
**严重程度:** Medium (P2) — 不影响核心功能，但显著影响用户体验

## 初步诊断

### 问题现象
用户在使用过程中可能遇到以下体验问题：
1. 登录/注册时缺乏实时反馈和引导
2. 搜索和筛选操作不够直观
3. 部分交互元素的可发现性差
4. 移动端布局不够优化
5. 缺少 loading 状态和骨架屏

### 根本原因
前端代码在功能实现上基本正确，但在 UX 细节上存在多处可优化空间：
- 部分交互元素的可见性和可发现性不足
- 缺少必要的用户引导和反馈机制
- 响应式设计在某些断点下体验不佳
- 可访问性（a11y）支持不完整

### 影响范围
- **功能:** 所有前端页面和组件
- **用户:** 所有用户，特别是移动端用户和新用户
- **数据:** 不影响数据完整性

## 风险评估

| 风险类型 | 等级 | 说明 |
|---------|------|------|
| 功能中断 | Low | 核心功能正常，仅体验问题 |
| 数据完整性 | None | 不影响数据 |
| 安全风险 | None | 无安全漏洞 |
| 用户流失 | Medium | 差的体验可能导致用户放弃使用 |

## 初步发现的 UX 问题清单

### 1. 登录/注册模块
- 注册时密码强度提示不明显
- 登录/注册切换时表单状态未完全重置
- 错误消息显示位置和样式可优化

### 2. 搜索和筛选
- 搜索框缺少清除按钮
- 搜索无 loading 状态
- 难度筛选使用 select 下拉，不如按钮直观

### 3. 题目卡片交互
- 答案区域的"编辑"和"重新生成"按钮默认隐藏（opacity-0）
- 收藏按钮点击区域偏小
- 频率数字缺乏说明

### 4. 练习面板
- 左右分栏 50/50 在小屏幕上拥挤
- 评估结果区域可能被截断
- 历史记录无分页

### 5. 抽测功能
- 题目数量输入无实时范围验证
- "换一批"无确认提示
- 评估完成后无自动滚动

### 6. 通用 UX
- 无骨架屏 loading
- 页面切换未滚动到顶部
- toast 错误持续时间过长（8s）
- 部分按钮缺少 aria-label
