# Bug 详细分析报告

**Bug ID:** BUG-001
**发现日期:** 2026-05-31
**状态:** 已确认

## 问题概述
点击用户头像后，下拉菜单（个人信息、题库模式切换、审核题库、退出登录）完全不可见。根本原因是 CSS `overflow: hidden` 裁剪了下拉菜单。

## 根本原因分析

### BUG-001: overflow-hidden 裁剪下拉菜单
- **位置:** `frontend/src/App.vue:5`
- **症状:** 点击头像按钮后，下拉菜单不可见。Vue 的 `showMenu` ref 状态正常切换（可通过 DevTools 确认），但 DOM 中的下拉元素被 CSS 裁剪。
- **根因:** 提交 `8947631` 为修复 320px 小屏幕溢出问题，在导航栏容器上添加了 `overflow-hidden`。该容器同时设置了 `h-14`（固定高度 56px）。UserMenu 的下拉菜单使用 `position: absolute; top: 100%` 定位，位于头像按钮正下方，即容器底部以下的区域。`overflow: hidden` 裁剪了所有超出 `h-14` 高度的内容。
- **影响:** 所有用户的头像下拉菜单功能完全失效
- **严重程度:** P0（Critical）

## 技术细节

### CSS 溢出裁剪机制
```css
/* 容器：固定高度 + 溢出隐藏 */
.container {
  height: 56px;        /* h-14 */
  overflow: hidden;    /* 裁剪所有溢出内容 */
}

/* 下拉菜单：绝对定位在容器下方 */
.dropdown {
  position: absolute;
  top: 100%;           /* 相对于父元素底部 */
  margin-top: 8px;     /* mt-2 */
  /* 结果：菜单顶部在 56px 处，完全在容器裁剪区域外 */
}
```

### 为什么之前的版本能工作
在提交 `8947631` 之前，导航栏容器没有 `overflow-hidden`，下拉菜单虽然超出容器范围，但不会被裁剪。

### 为什么添加 overflow-hidden
为了解决 320px 极小屏幕下导航栏内容水平溢出的问题。该提交还添加了 `shrink-0`、`min-w-0`、减小间距等措施。

## 复现步骤
1. 登录系统
2. 点击导航栏右侧的用户头像
3. 预期：出现包含"个人信息"、"题库模式"、"退出登录"等选项的下拉菜单
4. 实际：没有任何视觉变化，下拉菜单不可见

## 修复方向
使用 Vue 的 `<Teleport to="body">` 将下拉菜单和点击遮罩传送到 `<body>` 元素，使其脱离导航栏容器的 `overflow: hidden` 约束，同时保留 320px 小屏幕修复。
