# Bug 预览报告

**日期:** 2026-05-22
**问题:** 切换题库模式（公共/个人/混用）后，题库列表数据未更新，显示上一次模式的缓存数据
**严重程度:** High

## 初步诊断

### 问题现象
管理员身份下，来回切换公共题库和个人题库后：
- 个人题库只显示少量题目（实际应显示完整的个人题目列表）
- 切换回公共题库后，不再显示公共题库的题目
- 数据停留在第一次加载时的内容，切换模式无效

### 根本原因
`http.js` 中的 GET 请求缓存机制（30 秒 TTL）导致问题。

`fetchMasterBank()` 的请求 URL 始终为 `/api/master-bank?page=1&page_size=500&sort=frequency_desc&compact=true`，**不包含 bank_mode 参数**（bank_mode 由服务端从用户 DB 记录中读取）。缓存的 key 是 URL 本身，因此切换 bank_mode 后，`get()` 函数命中缓存返回旧数据，不会向服务端发起新请求。

`handleBankModeChanged` 函数调用 `fetchTableData()` 前未清除 master-bank 的缓存。

### 影响范围
- **功能:** 题库模式切换完全失效
- **用户:** 所有使用题库模式切换功能的用户（管理员和普通用户均受影响）
- **数据:** 不影响数据完整性，仅影响前端展示

## 风险评估

| 风险类型 | 等级 | 说明 |
|---------|------|------|
| 功能中断 | High | 题库模式切换功能完全失效 |
| 数据完整性 | Low | 仅前端缓存问题，不影响后端数据 |
| 安全风险 | None | 不涉及安全问题 |
