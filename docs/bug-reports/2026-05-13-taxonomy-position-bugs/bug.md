**状态:** 已确认

## BUG-001: AI分类生成使用错误的岗位

### 问题概述
选择"后端开发"岗位后，点击"AI智能生成分类"，生成的分类仍然是基于"agent开发"岗位。

### 根本原因
- **位置:** `backend/app/routers/profile.py:378`
- **症状:** 生成的分类与用户选择的岗位不匹配
- **根因:** 使用了 `get_current_job_position()` 获取全局岗位，而不是 `get_user_job_position(user_id)` 获取用户个人岗位
- **影响:** 所有用户的AI分类生成功能都使用错误的岗位
- **严重程度:** P1

### 复现步骤
1. 登录系统
2. 在系统配置中选择"后端开发"岗位
3. 点击"AI智能生成分类"
4. **预期:** 生成后端开发相关的分类
5. **实际:** 生成agent开发相关的分类

## BUG-002: 目标岗位添加无响应

### 问题概述
在目标岗位输入框中输入新岗位名称后，点击"添加"按钮无响应。

### 根本原因
- **位置:** 需要进一步调试
- **症状:** 点击添加按钮后没有反应，没有成功提示也没有错误提示
- **根因:** 可能是API调用失败但错误被吞掉
- **影响:** 用户无法添加新岗位
- **严重程度:** P2

### 复现步骤
1. 登录系统
2. 进入系统配置
3. 在目标岗位输入框输入新岗位名称
4. 点击"添加"按钮
5. **预期:** 岗位被添加，显示成功提示
6. **实际:** 无任何响应
