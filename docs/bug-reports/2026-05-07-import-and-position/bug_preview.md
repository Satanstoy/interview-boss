# Bug 预览报告

**日期:** 2026-05-07
**问题:** 导入功能字段名不匹配 + JD 缺少岗位隔离 + 招聘季未传递
**严重程度:** High

## 初步诊断

### 问题现象
1. 导入界面选择"JD"或"面经"类型无效，后端始终走 LLM 自动识别
2. 招聘季下拉框为空，无预设选项
3. 切换目标岗位后面经数据不变（所有面经 job_position 为空）
4. JD 数据不按岗位隔离（jd 表无 job_position 字段）
5. 所有导入默认进入个人题库，无法选择提交到公共题库

### 根本原因
1. 前端发送字段名 `type`，后端期望 `content_type`（字段名不匹配）
2. App.vue 未加载 `available_seasons` 且未传递给 StagingPanel
3. 面经导入时 `job_position` 未正确写入（历史数据为空）
4. jd 表 schema 缺少 `job_position` 列
5. 前端未发送 `target` 字段

### 影响范围
- **功能:** 导入功能的核心流程全部受影响
- **用户:** 所有用户
- **数据:** 已有数据缺少岗位标记，影响岗位切换功能

## 风险评估

| 风险类型 | 等级 | 说明 |
|---------|------|------|
| 功能中断 | **High** | 类型选择、招聘季选择均无效 |
| 数据完整性 | **High** | JD 无岗位隔离，面经岗位字段为空 |
| 安全风险 | None | 无安全风险 |
