# Bug 预览报告

**日期:** 2026-05-10
**问题:** 161 条题目的来源展开后只有链接没有原始题目文本
**严重程度:** High

## 初步诊断

### 问题现象
高频题库中部分题目展开来源后，只显示面经链接（公司/轮次 + [原文]），不显示该面经中原始的题目文本。影响 161/210 条题目（76.7%）。

### 根本原因
`original_question_sources` 字段为空（`[]`），前端 `dedupedSources` 计算属性无法从空的 oqs 中建立 URL → 原始题目文本的映射。

两个代码路径导致 oqs 为空：
1. **重建题库**（`master_bank.py:325-326`）：独立题目（未聚类合并）的 oqs 被清空为 `[]`
2. **增量更新新建题目**（`operations.py:213-216`）：INSERT 语句未包含 `original_question_sources` 列，默认 NULL

### 影响范围
- **功能:** 来源展开后无法看到原始题目文本
- **用户:** 所有用户
- **数据:** 161 条题目缺失 oqs 数据，9 条 oqs 有空 sources 条目

## 风险评估

| 风险类型 | 等级 | 说明 |
|---------|------|------|
| 功能中断 | High | 76.7% 的题目来源无法显示原始文本 |
| 数据完整性 | High | 161 条题目缺失 oqs 数据 |
