# Bug 预览报告

**日期:** 2026-05-13
**问题:** AI智能生成功能调用失败，返回500错误
**严重程度:** High

## 初步诊断

### 问题现象
用户在前端点击"AI智能生成分类"按钮后，页面显示"AI生成失败"，后端日志显示LLM API调用返回500错误。

### 根本原因
外部LLM服务（`token-plan-cn.xiaomimimo.com`）返回500 Internal Server Error，导致我们的API调用失败。

从日志可以看到：
```
HTTP Request: POST https://token-plan-cn.xiaomimimo.com/v1/chat/completions "HTTP/1.1 500 Internal Server Error"
Error code: 500 - {'timestamp': 1778658374240, 'path': '/v1/chat/completions', 'status': 500, 'error': 'Internal Server Error', 'requestId': '9e898d39-350971'}
```

### 影响范围
- **功能:** AI智能生成分类功能完全不可用
- **用户:** 所有尝试使用AI生成功能的用户
- **数据:** 不影响数据完整性，只是生成功能失败

## 风险评估

| 风险类型 | 等级 | 说明 |
|---------|------|------|
| 功能中断 | High | AI生成功能完全不可用 |
| 数据完整性 | Low | 不影响现有数据 |
| 安全风险 | Low | 无安全风险 |

## 问题分析

### 问题1: 外部LLM服务不可用
- **现象:** LLM API返回500错误
- **原因:** 外部服务故障（`token-plan-cn.xiaomimimo.com`）
- **影响:** 所有LLM相关功能都可能受影响

### 问题2: 错误信息不够详细
- **现象:** 前端只显示"AI生成失败"
- **原因:** 后端捕获异常后返回通用错误信息
- **影响:** 用户无法了解具体失败原因

## 建议修复方案

### 方案1: 改进错误处理（推荐）
- 区分不同类型的错误（网络错误、LLM服务错误、解析错误）
- 提供更详细的错误信息给用户
- 添加重试机制

### 方案2: 添加备用LLM服务
- 配置多个LLM服务端点
- 主服务失败时自动切换到备用服务

### 方案3: 本地缓存分类建议
- 预生成常见岗位的分类建议
- LLM服务不可用时使用缓存
