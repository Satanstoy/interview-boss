# 隐私政策

> 最后更新：2026-08-15
> 版本：v1.0

本隐私政策说明 InterviewBoss 如何收集、使用、存储、共享和保护你的个人信息，以及你对此拥有的权利。

本服务是一套自称部署（self-hosted）的 AI 面试备战工作台，部署实例由运营者控制。数据控制者为本部署实例的运营者；如你通过他人运营的实例使用本服务，请以该运营者公布的联系方式为准。

## 1. 我们收集哪些数据

按实际功能，我们可能处理以下类别信息：

| 类别 | 具体内容 | 收集方式 | 对应模块 |
|------|---------|---------|---------|
| 账户信息 | 用户名、密码（bcrypt 哈希）、邮箱、管理员标记、题库可见模式、分享默认值 | 注册/登录时提供 | users 表、认证模块 |
| JD/面经文本 | 粘贴或上传的 JD、面经文本、截图 OCR、来源链接 | 提交导入 | jd / interview / questions_detail / sources |
| 简历数据 | 简历文件名、解析出的纯文本 | 上传简历/简历优化 | user_resumes |
| 练习/复习记录 | 练习作答、评分、复习事件、熟练度(SM-2-lite)、题单、收藏 | 刷题与复习时生成 | user_practice_history / practice_review_events / user_question_review / practice_decks |
| 模拟面试记录 | 与 AI 面试官的对话、回合、工具调用痕迹、被抽题目 | 模拟面试时生成 | chat_conversations / chat_messages / chat_turns / chat_tool_traces |
| 语义记忆 | 从对话自动抽取的长期记忆（岗位/技能/目标/偏好） | 对话后自动抽取 | chat_memories / memory_recall_service |
| 音频转写 | 上传的音频及其转写文本 | 音频功能 | deepgram_service（第三方转写） |
| 手撕代码 | 提交代码、题目、AI 评审、题单 | 手撕代码练习 | coding_submissions / coding_playlists |
| 系统与审计数据 | 登录失败、令牌(JTI)、邮箱验证码、LLM 用量、审计日志、请求日志 | 系统自动生成 | login_failures / refresh_tokens / email_verification_codes / llm_usage / admin_assistant_log |
| 配置数据 | LLM 配置(Base URL/模型/API Key)、搜索配置、MCP Token、偏好 | 设置页配置 | user_llm_config / user_search_config / mcp_tokens / user_profile |

## 2. 我们如何使用这些数据

我们仅将上述数据用于提供并改进本服务核心功能：

- 提交与题库：解析 JD/面经、提取面试题、聚类去重、生成参考答案。
- 练习与复习：调度今日复习、间隔复习、统计足迹与岗位准备度。
- 模拟面试：结合简历与岗位背景开展多轮 AI 面试、反馈与复盘。
- 答案增强：在你显式开启联网搜索时，用实时搜索结果增强答案。
- 账号与服务安全：身份验证、登录保护、速率限制、审计与故障排查。
- 帮助与支持：邮箱绑定、密码重置、数据导出与账号删除。

我们不会将个人信息用于广告投放，不会向第三方出售或出租，也不用于无关的行为画像。

## 3. 存储位置与期限

- 存储位置：主要数据存放在本部署实例的 SQLite 数据库（backend/data/interview-boss.db），运行于部署运营者控制的服务器；运行态缓存与队列使用 Redis。存储位置由部署运营者决定。
- 存储期限：保留账号期间，核心功能数据默认长期保留。以下数据有期限性清理：登录失败记录、邮箱验证码等由每日定时任务按保留期（30-90 天，父任务血缘保护）清理；失效令牌、MCP 会话随保留期清理。详见《账号删除》。

## 4. 数据共享与第三方处理

我们不会对外销售或出租你的个人信息。仅在以下情形共享：

1. 法律、法规、监管或司法程序要求。
2. 必要服务提供：为提供特定功能，由第三方技术供应商处理最小必要数据。当前可能涉及的第三方见《子处理器清单》，包括 LLM 服务商（OpenAI 兼容/Anthropic/MiMo 等，按你的配置）、SiliconFlow（embedding）、Deepgram（转写）、联网搜索服务商（Tavily/Brave/Bocha/Exa，需显式开启）、SMTP 邮件服务、以及仅构建阶段使用的镜像源（npm/PyPI/APT）。

LLM、搜索等第三方均按你的个人配置启用；未配置对应 API Key 时相应功能不可用，数据不会被发送。

## 5. 用户权利

- 查看/访问：在设置页或相应功能页面查看账户、题库、练习与聊天记录。
- 更正：修改用户名、邮箱、简历、偏好与配置。
- 导出：如部署实例提供导出能力可请求导出；否则联系运营者协助。
- 删除：请求删除账号及其关联数据，见《账号删除》。
- 撤回同意/关闭可选功能：可随时关闭或移除联网搜索、邮箱绑定等配置。

要行使权利请联系本实例运营者（见第 6 节），通常 7-15 个工作日响应。

## 6. 联系我们

- 处理负责人：本部署实例的运营者（自托管场景下即部署方）。
- 渠道：通过部署方公布的邮箱/站内反馈入口；若实例配置 SMTP 支持邮箱（SMTP_FROM/SMTP_USERNAME），可作为反馈渠道。
- 时效：核实身份后及时处理，删除/导出按保留规则执行。

## 7. 未成年人

本服务面向求职准备，主要面向成年用户，不面向未满 14 周岁未成年人，亦不有意收集其信息。如发现已收集，请联系我们核实后尽快删除。

## 8. 信息安全

- 密码以 bcrypt 哈希保存，不存明文。
- 认证使用 JWT 双 Token（Refresh 存 HttpOnly Cookie）+ CSRF + 安全响应头 + 速率限制 + 登录失败锁定。
- 数据软删除 + 回收站；.gitignore 排除 .env、数据库等敏感文件。
- SQLite WAL + 破坏性操作前自动整库备份到 backend/data/backups/。

本政策可能随功能演进或合规要求更新。重大变更通过本页面（版本/日期）及部署方公告通知。
