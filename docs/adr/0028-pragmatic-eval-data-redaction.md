# ADR-0028: 1.0 采用轻量、边界清晰的评测数据脱敏

**Status:** accepted

评测系统需要保护简历和面试内容中的明显个人信息，但 1.0 不建设过度复杂的隐私平台。评测默认使用合成或固定 Fixture；只有在生产采样有明确价值时，才允许经过基础脱敏后进入评测 Artifact 或 Benchmark 候选集。

1.0 的最小边界：

- 采样入口优先移除姓名、电话、邮箱、明确的用户 ID、个人 URL 和明显账号标识；
- 原始生产记录不直接复制到长期 Artifact，先生成脱敏副本；
- 复用现有管理员认证、权限和访问日志，不新增独立权限中心；
- 不承诺完整 PII 检测，不引入企业级 DLP、字段级加密或额外隐私服务；
- 脱敏失败或内容不确定时，样本不得自动晋升为长期 Benchmark，应由管理员处理或改用合成 Fixture。

该边界保护长期可追溯性和实现速度之间的平衡；后续如果评测数据规模、合规要求或外部协作场景发生变化，再单独升级隐私架构。
