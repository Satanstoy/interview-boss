# ADR-004: GPT 拥有面试策略决策权

**Status:** accepted

InterviewBoss MCP 不替 GPT 决定追问、换题、澄清、切换能力维度或结束面试。GPT 根据当前状态事实和已加载的面试节奏 skill 选择下一步策略；InterviewBoss 负责维护状态事实、执行硬约束和版本校验、持久化决策，并拒绝非法或过期的状态变更。

这保留了 GPT 在自然对话中的适应能力，同时避免 GPT 直接修改服务端状态。原有“代码状态机拥有面试路由权”的 ADR 被本决策取代；服务端仍然拥有数据和状态的一致性，但不拥有默认的面试策略。

为减少 MCP 往返，回答事实和 GPT 的策略决策通过一次面试回合推进命令提交；服务端在同一原子操作中保存回答、校验动作并推进状态。复杂的报告分析可以异步执行，不阻塞每轮对话。

策略决策使用固定的面试动作枚举，GPT 可以附带 reason 和 focus，但不能通过自由文本创建未定义动作。服务端依据当前状态校验动作是否可用。

候选人的明确控制指令优先于 rhythm skill 的默认节奏：结束、跳过和切换方向都作为正式面试事件记录，并由 GPT 映射为受约束的面试动作。

面试开始或续接时自动加载并固定面试相关 skill 版本；进行中的面试不因服务端发布新 skill 而中途改变规则，新面试使用最新可用版本。

面试回合推进携带期望的面试状态版本；版本过期时服务端拒绝覆盖并返回冲突，让 GPT 重新读取状态后再作决策。相同客户端请求标识的重试保持幂等。

导入的面试原文、简历和外部分析属于不可信面试内容，只能作为分析证据，不能改变系统指令、工具权限或面试状态。
