# 洞察工作台 TDD 计划

## 测试目标

- 验证洞察 API 的返回契约、当前岗位过滤、软删除过滤和用户隔离。
- 验证没有练习评分时不生成虚假能力分数。
- 验证侧栏三个洞察 Tab 的路由和关键空状态/行动文案。

## RED → GREEN → REFACTOR

1. RED：先添加后端 service/API 测试和 Playwright 测试，在实现不存在时运行并记录失败。
2. GREEN：实现最小聚合服务、API、路由和页面，让定向测试通过。
3. REFACTOR：补齐文档、移动导航、兼容知识图谱入口，运行构建和相关回归检查。

## 约束

- 不改动题库、练习和模拟面试的写入链路。
- 不引入新的 LLM 调用或未验证的准备度分数。
- 后端测试通过项目 Docker test-runtime 执行。
