# REFACTOR 阶段记录

## 重构与边界检查

- 保持聚合逻辑在 service，router 只做认证和 `run_db` 调度。
- 题库查询复用 `build_bank_where_clause`，避免洞察与题库页面出现不同的岗位/可见性口径。
- 练习历史按 `user_id` 且只与当前岗位题库交集，避免读取其他用户的个人证据。
- 没有评分时使用 `not_started` / `insufficient` 和显式说明，不生成虚假能力分数。
- 知识图谱不再作为一级 Tab，但保留旧路由和现有组件，降低迁移风险。
- 行动卡片和复盘入口透传当前路由 query，避免生产用户误进入 `preview=1`。
- 更新后端、前端、业务组件、composable、API service、E2E 目录约束文档。

## 仍待后续

- 移动端能力矩阵可以进一步提供卡片式行视图；当前用横向滚动保证字段不丢失。
- 结构化练习评分积累后，再设计训练进度和遗忘提醒 Tab。
