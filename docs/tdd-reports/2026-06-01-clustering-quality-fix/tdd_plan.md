# TDD 开发计划

**功能名称:** 聚类质量优化 - 减少孤岛数据
**日期:** 2026-06-01
**TDD 状态:** 🔴 红灯阶段准备

## 问题描述

三段式聚类（精确匹配→FAISS embedding→LLM批量验证）产生大量孤岛数据（42%+ 单例题），
主要原因：
1. FAISS 阈值 0.75 过高，bge-small-zh-v1.5 小模型对中文语义相似但措辞不同的题目 cosine 仅 0.6-0.7
2. 未按 cat2 分组，跨领域题目干扰 embedding 和 LLM 判断
3. FAISS top-K=5 太小，遗漏传递性关系
4. 批量验证 prompt 过于简化，缺少分类上下文

## 优化方案

参考 ClusterFusion (2025) 论文思路：embedding 预组织 + LLM 语义聚类核心

### 改进点
1. **降低 embedding 阈值**: 0.75 → 0.55（粗筛，不直接决定合并）
2. **按 cat2 分组聚类**: full_recluster 先按 cat2 分组
3. **增大 FAISS top-K**: 5 → 10
4. **LLM 分组聚类替代批量验证**: 对每个 cat2 组，用 LLM 对 embedding 候选做语义分组
5. **传递性合并**: 通过 union-find 处理传递性关系

## 验收标准

- [ ] 已知重复题目对（如 "TCP三次握手" vs "TCP为什么是三次握手"）能被正确合并
- [ ] 相似但不同知识点（如 "缓存穿透" vs "缓存雪崩"）不被错误合并
- [ ] 按 cat2 分组后，跨领域题目不会互相干扰
- [ ] 孤岛率从 42% 降至合理水平（目标 < 20%）
- [ ] 现有增量聚类功能不受影响
