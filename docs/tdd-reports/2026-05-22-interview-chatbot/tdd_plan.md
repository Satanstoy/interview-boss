## 需求描述

## 验收标准

- [ ] 消息存储和检索正确（保存、按时间排序、limit）

- [ ] FTS5 检索返回相关题目
- [ ] Chat API 端点返回正确响应
- [ ] 边界情况处理（空输入、不存在的会话、权限隔离）
