## 设计决策

**来源:** 研究 DeepSeek/ChatGPT 的标题生成机制
- DeepSeek 在对话开始时基于首条用户消息生成标题
- 标题保持静态（不随对话更新）
- 使用轻量 LLM 调用提取核心话题

**实现:**
- `title_service.py` — 标题生成服务
  - 短消息（≤10 字符）直接用作标题（零 LLM 成本）
  - 长消息用 LLM 提取核心话题（≤20 字符）
  - LLM 失败时降级为智能截断
- `chat.py` — 集成到 send_message 端点
  - 仅在 title 为默认值（"新对话"/"JD定制面试"）时触发
