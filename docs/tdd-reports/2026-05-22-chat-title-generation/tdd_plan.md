# TDD 开发计划

**功能名称:** Chat 对话标题自动生成（基于首条用户消息）
**日期:** 2026-05-22
**TDD 状态:** 🔴 红灯阶段准备

## 需求描述

模仿 DeepSeek/ChatGPT 的做法，在用户发送第一条消息时，用轻量 LLM 调用从消息中提取/生成一个简短的对话标题，替换当前的 `content[:30]` 硬截断逻辑。

## 验收标准

- [ ] 中文消息能生成有意义的标题（如 "Redis 缓存策略讨论"）
- [ ] 英文消息能生成中文标题
- [ ] 标题长度 ≤ 20 字符
- [ ] 短消息（<10 字符）直接用作标题，不调用 LLM
- [ ] LLM 失败时降级为截断
- [ ] 仅在 title 为默认值时触发（"新对话" 或 "JD定制面试"）
